# ExoplanetEarth_EiB
Repository for Lowe et al., "Earth as an Exoplanet: From Habitable to Biodiverse". </BR>
Pipeline for: </BR>
  i) Processing NASA PACE (Plankton, Aerosol, Cloud, ocean Ecosystem) data via Earthaccess/Earthdata; </BR>
  ii) Comparing to historical Galileo Earth flyby data; </BR>
  iii) Determining the detectability of atmospheric reflectance signatures for PACE-like parameters. </BR>
