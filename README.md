# ExoplanetEarth_EiB
Repository for Lowe et al., "Earth as an Exoplanet: From Habitable to Biodiverse". </BR>
Pipline for: 
  i) Processing NASA PACE (Plankton, Aerosol, Cloud, ocean Ecosystem) data via Earthaccess/Earthdata;
  ii) Comparing to historical Galileo Earth flyby data;
  iii) Determining the detectability of atmospheric reflectance signatures for PACE-like parameters.
