# ExoplanetEarth_EiB
Repository for Lowe et al., "Earth as an Exoplanet: From Habitable to Biodiverse". Ran in *Visual Studio Code.* </BR>
i) Process NASA PACE (Plankton, Aerosol, Cloud, ocean Ecosystem) data via Earthaccess/Earthdata; </BR>
ii) Compare to historical Galileo Earth flyby data; </BR>
iii) Calculate biosignature detectability acrossing resolving powers and signal-to-noise ratios. </BR>
</BR>
**TO RUN:** </BR>
1) Clone this repository </BR>
2) Run in command line: conda env create -f environment.yml </BR>
3) Activate the environment </BR>
4) Run the notebook (created in *Visual Studio Code*, update data pathway in Cell 1 if necessary) </BR>
</BR>
